# Pinxit Finder – Daten

Öffentliche Datendatei für die App „Pinxit Finder“ (Arbeitsname): aktuelle Kunstausstellungen,
Sammlungen und Häuser in der DACH-Region – Titel, Daten, Orte, Öffnungszeiten, Eintritt.

- `finder-daten.json` – wird wöchentlich automatisch erzeugt und hier veröffentlicht.
- Abruf: `https://bigbossalphaultrabig.github.io/pinxit-finder-daten/finder-daten.json`

Quellen: Websites der Häuser, OpenStreetMap (© OpenStreetMap-Mitwirkende, ODbL), Wikidata.
Alle Angaben ohne Gewähr. Häuser, die nicht aufgeführt werden möchten, melden sich bitte über die App („Fehler melden“).
